# 平台编辑策略

这是仓库默认策略，更新于 2026-10-20，未作为各平台最新官方审核规则核验。

| 平台 | 编辑方向 | 脚本预处理 |
|---|---|---|
| 头条 | 回答问题、清晰场景与短段落 | 分离发布设置、保留事实 |
| 搜狐 | 中性标题、克制表达 | 移除标题中的榜单/推荐/绝对化修饰、电话 |
| 知乎 | 充分论证、判断框架、引用依据 | 保留主稿供进一步编辑，不添加固定套话 |
| 36氪 | 产业与商业观察，有相应材料 | 移除电话，其余交给编辑 |

共享检查在 `doubao-geo-publisher/scripts/geo_core.py`。不对正文做全局禁词替换，避免改变事实。

年份、数字、关键词频次、参考来源位置不是固定门槛。来源可另存证据文件。自动检查只覆盖部分措辞，不代表平台审核或行业法律审查。

发布前应核对现行平台文档；补充官方规则需记录链接、核验日期和适用范围。没有依据的“发文间隔”“平台引用偏好”不能写成事实。
