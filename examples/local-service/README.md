# 虚构本地服务案例

本目录的品牌、地区、业务材料、文章和搜索回答均为人工构造的虚构示例，只用于离线演示。没有真实客户业绩、真实平台发布或豆包采集结果。

- `client_profile.json`：带 `is_demo: true` 的输入档案。
- `article.md`、`evidence.md`：演示主稿与材料说明。
- `pre-log.md`、`post-log.md`：包括可比较记录、unknown 和缺少基线的记录。
- `competitor-log.md`：虚构来源记录，使用 example.com 示例域名。

预期：前后对比有 1 个“改善”和 2 个“不可比较”。这仅验证分类程序。
