# 模板使用方式

正式使用先向用户询问资料，再把用户提供的信息填入模板。品牌、业务、地区、目标和证据都不预设客户值；不知道的字段留空并标为待确认。

- [空白客户档案](../skills/doubao-geo-publisher/assets/client_profile.template.json)
- [分阶段询问清单](../skills/doubao-geo-publisher/assets/intake_questionnaire.template.md)
- [客户资料收集流程](../docs/client-intake.md)
- [文章 Brief](article-brief.template.md)
- [Excel 流程模板](GEO自动化流程表格模板.xlsx)：提示行用于说明怎么填写，实际记录另起一行。

独立离线案例位于 `examples/`，只有明确运行演示或测试时使用，不是正式客户的默认资料。
